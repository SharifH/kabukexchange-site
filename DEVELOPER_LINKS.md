# Developer and API Link Configuration

Edit only `site-config.json` under `developerLinks`:

- `developerDocsUrl`: Developer guides/documentation destination. Keep `/developers/guides/` now; later change to `https://developers.kabukexchange.com/` or `https://docs.kabukexchange.com/guides/`.
- `apiReferenceUrl`: API reference destination. Keep `/developers/api/` now; later change to your Swagger, Redoc, Stoplight, ReadMe, or custom API portal URL.
- `sandboxUrl`: Sandbox access or application destination.
- `changelogUrl`: Release notes/changelog destination.
- `integrationSupportUrl`: Technical integration enquiry destination.

## Page roles

- **How It Works** explains business and data flow to mixed commercial, operations, product, and technical audiences.
- **Developer Platform** is the technical landing page.
- **Developer Guides** explain implementation patterns and the integration lifecycle.
- **API Reference** contains or links to endpoint-level documentation.
- **Resources** routes each visitor to the appropriate one of these destinations.
